# StreamWay
A website browser that contains links for movies/series such as real life, anime and even live sports games.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The page layout (what's on the page) |
| `css/style.css` | How it looks: colors, spacing, the moving lights |
| `js/data.js` | **Your content**: the three sections and the list of services to add |
| `js/art.js` | The pictures drawn on the three TV screens |
| `js/app.js` | How it works: pages, search, favorites, the pop-up window |
| `images/tv-scene.jpg` | The photo on the Movies & TV screen |

To add a service, open `js/data.js` and add a line inside `SITES`.
